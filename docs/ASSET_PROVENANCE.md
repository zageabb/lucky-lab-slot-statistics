# Asset provenance

The three PNG concept images in `visuals/` were supplied in the design pack and generated specifically for it using OpenAI image generation. They are mood and hierarchy references only and are not shipped as application backgrounds.

The seven production reel symbols in `app/static/symbols/` (`clover`, `harp`, `horseshoe`, `rainbow`, `emerald`, `crown`, and `gold_pot`) are original SVG illustrations created as project code on 14 August 2026. They use elementary paths and gradients, contain no copied commercial artwork, and include separate HTML text alternatives.

The UI stylesheet and canvas chart renderer are original project code. No external font, CDN, tracking, commercial game asset, or network dependency is used at runtime.
